# Assets

`so_arm100.xml`, `so_arm100_arm.xml` and everything in `so_arm100_meshes/` are
taken from [`mujoco_menagerie`](https://github.com/google-deepmind/mujoco_menagerie)
(`trs_so_arm100`), Apache-2.0 — see `SO_ARM100_LICENSE`.

`so_arm100_arm.xml` is the menagerie model with three changes, all marked in the
file:

1. the `<keyframe>` and `<option>` blocks are removed so the model can be
   `<attach>`-ed twice into a larger scene without clashing;
2. a `tcp` site is added inside `Fixed_Jaw` at the midpoint of the finger pads —
   this is the frame the IK solves for;
3. a `wrist` camera is added to `Fixed_Jaw`, placed behind and above the jaw so
   it sees the fingers and what is between them.

The dinner-table scene itself is generated by `dinnerbot/sim/build_scene.py`; no
scene XML is checked in, because randomising geom sizes, masses and frictions
requires regenerating and recompiling the model per seed.
